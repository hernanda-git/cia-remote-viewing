REMOTE VIEWING (RV) SESSION XLIV 


1. (8S) This report provides documentation of a remote 
viewing session conducted for training purposes to enhance a 
remote viewer's demonstrated ability. 


2. (S) The remote viewer's impressions during this session 
showed several meaningful correlations to a site contiguous 

to the designated target. The remote viewer was able to 
adjust to the change in on-target time with minimal disturb- 
ances. He was very relaxed and appeared able to concentrate. 
He had several very clear images which he was able to describe 
very well. 


3. (S) The protocol used for this session is detailed in 
the document, Grill Flame Protocol, AMSAA Applied Remote 
Viewing Protocol (S), undated. 


4. (S) Following is a transcript of the viewer's impressions 
during the remote viewing session. At TAB A are drawings made 
by the viewer reference his impressions of the target site. 
Photographs of the target site are on file in GRILL FLAME 
Session Report Number XLVI.
