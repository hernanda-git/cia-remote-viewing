SUMMARY ANALYSIS 


REMOTE VIEWING (RV) SESSION C 2 


1. (S) This report provides documentation of a remote 
viewing session conducted for training purposes to enhance 
a remote viewer's demonstrated ability. 


2. (S) There appearsto be no target correlation in this session 
The remote viewer had difficulty developing his imagery. He was 
able to relax and concentrate but obviously did not focus on the 
designated target. The viewer said his images became very clear 
as the session progressed. The viewer did not have any feeling 
as to how well he had done. He feels he must have "gone"some- 
where because his imagery was so clear. No explanation for lack 
of target correlation is apparent at this point. The viewer did 
state before the session that he was very hyper and not at all 
calm. 


3. (S) The protocol used for this session id etailed in 
the document, Grill Flame Protocol, AMSAA Applied Remote 
Viewing Protocol (S), undated. 


4. (S) Following is a transcript of the viewer's impressions 


during the remote viewing session. At TAB B is available target 
descriptive data.
