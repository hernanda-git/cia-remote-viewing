SUMMARY ANALYSIS 


REMOTE VIEWING (RV) SESSION #854 


1. (S/NOFORN) This report provides documentation of a remote viewing 
session conducted for training purposes only. 


2. (S/NOFORN) Post analysis on target viewing indicates the viewer had 
quite a bit of correlation to the target. The viewers gestaltic impress-~ 
ions were very basic in content; i.e., circle, pyramid, square, etc., but 
were exceptionally accurate in their construction (one relating to the 
other) in description of the actual target; an outside theater. The 
viewers immediate comments following the session and being briefed on his 
actual target were that he was disappointed in himself for seeing the tar- 
get but not being able to put it into words, as well as having clearly 
described what he did about the target putting the target in an upsidedown 
perspective. 


3. (S/NOFORN) The protocol used for this session is detailed in the 
document, Standard Remote Viewing Protocol (Remote Target) by Harold E. 
Putthoff and Russel Targ, November 1978. 


4. (S/NOFORN) Following is a transcript of the viewer impressions during 

the remote viewing session. At TAB A is the narrative and drawings per- 
tinent to the target. At TAB B is the actual map sheet from which the 
target was drawn, as well as the cuing data utilized to initiate the session.
